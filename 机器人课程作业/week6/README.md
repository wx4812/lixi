# Week 6: 传感器介绍与 ROS2 KITTI 实验

## 实验内容
本周完成了以下任务：
1. 机器人常用感知传感器（相机、激光雷达）工作原理学习
2. 自动驾驶经典 KITTI 数据集格式与结构解析
3. 在 ROS2 中读取、解析 KITTI 数据并完成话题发布与可视化

## 运行命令
```bash
# 启动 KITTI 数据话题发布节点
ros2 run kitti_ros kitti_data_publisher

# 打开 RViz2 查看传感器点云与图像数据
rviz2
实验内容
 
本周完成了以下任务：
 
1. 机器人常用传感器（激光雷达、相机）原理学习

2. KITTI数据集格式与数据结构解析

3. ROS2中KITTI数据读取、话题发布与可视化

 遇到的问题
 1. 问题：KITTI数据无法正常解析读取
解决：修正数据集路径、安装对应依赖包

2. 问题：RViz无法显示点云/图像数据
解决：确认话题名称、数据类型与坐标系匹配
 
学习心得
 
了解了机器人主流环境感知传感器的工作原理，掌握了自动驾驶经典KITTI数据集在ROS2中的接入与可视化方法，对机器人感知模块建立了完整认知。
