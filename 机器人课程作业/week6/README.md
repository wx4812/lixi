## 四、机器人常用传感器介绍

机器人感知环境通常需要依赖多种传感器。不同传感器获取的数据类型不同，适合完成的任务也不同。

### 1. 相机

相机可以获取二维图像信息，常用于目标检测、车道线识别、图像分类、语义分割等任务。相机数据直观、信息量大，但容易受到光照、天气和遮挡影响。

### 2. 激光雷达

激光雷达通过发射激光并接收反射信号，计算周围物体到传感器的距离。激光雷达可以生成三维点云数据，常用于建图、定位、避障和自动驾驶环境感知。相比相机，激光雷达对距离测量更准确，但成本较高，数据处理也更复杂。

### 3. 相机与激光雷达的区别

相机主要提供颜色和纹理信息，激光雷达主要提供空间距离和几何结构信息。在机器人系统中，两者经常结合使用，实现更稳定的环境感知。

## 五、KITTI 数据集简介

KITTI 是自动驾驶领域常用的公开数据集，包含真实道路场景下采集的图像、激光雷达点云、GPS/IMU 和标注信息。它常用于自动驾驶感知、三维目标检测、SLAM 和多传感器融合研究。
