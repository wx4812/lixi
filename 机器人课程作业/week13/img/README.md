## 四、四足机器人基础介绍

四足机器人是一类具有四条腿的移动机器人。相比轮式机器人，四足机器人能够适应更加复杂的地形，例如台阶、斜坡、草地和不平整路面。四足机器人通常由机身、四条腿、多个关节电机、传感器和控制系统组成。

每条腿一般包含多个自由度，常见结构包括髋关节、膝关节和踝关节。通过控制不同关节的角度变化，机器人可以调整足端位置，从而实现站立、迈步和转向。

## 五、四足机器人运动方式

四足机器人的运动依赖步态控制。步态是指四条腿按照一定顺序抬起和落下的运动模式。

常见步态包括：

1. **站立步态**：四条腿同时支撑地面，保持机身稳定。
2. **行走步态**：每次移动一条腿或两条腿，速度较慢但稳定性较高。
3. **小跑步态**：对角线两条腿同步运动，速度较快，对控制要求更高。
4. **转向步态**：左右腿运动幅度不同，从而改变机器人方向。

在实际控制中，需要考虑机器人重心、足端轨迹、关节角度和地面接触状态。如果控制不稳定，机器人可能会出现抖动、倾斜或摔倒。
