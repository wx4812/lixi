## 四、Linux 目录与权限基础

Linux 系统中的文件和目录采用树状结构组织，根目录为 `/`。常见目录包括：

- `/home`：用户主目录
- `/etc`：系统配置文件目录
- `/usr`：系统软件和库文件目录
- `/opt`：第三方软件安装目录，ROS2 常安装在这里
- `/tmp`：临时文件目录

在 Linux 中，文件权限通常包括三类：

1. `r`：read，读取权限
2. `w`：write，写入权限
3. `x`：execute，执行权限
