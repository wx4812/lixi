# Week 7: Markdown 与 GitHub 作业整理

## 一、实验目的

本周实验主要学习 Markdown 基础语法和 GitHub 仓库作业整理方法，并对前几周的课程作业进行统一归档。通过本次实验，我希望掌握使用 Markdown 编写清晰 README 文档的方法，熟悉 Git 的暂存、提交和推送流程，并让 GitHub 仓库中的课程作业结构更加规范、易读和便于评分。

## 二、实验内容

本周完成了以下任务：

1. 学习 Markdown 标题、列表、代码块、链接、图片和表格等常用语法。
2. 统一整理前几周课程作业的 README 文件。
3. 检查各周作业目录中的图片路径和文件结构。
4. 使用 Git 命令完成本地暂存、提交和推送。
5. 将全部本地内容同步到 GitHub 远程仓库。
6. 总结 Markdown 文档规范和 GitHub 作业提交经验。

## 三、实验环境

- 操作系统：Windows + WSL Ubuntu 22.04
- 编辑工具：VS Code
- 代码托管平台：GitHub
- 版本控制工具：Git
- 文档格式：Markdown
- 远程仓库：GitHub Repository

## 四、Markdown 基础语法

Markdown 是一种轻量级标记语言，常用于编写 README、课程笔记、项目说明和技术文档。它语法简单，阅读性好，非常适合 GitHub 作业提交。
