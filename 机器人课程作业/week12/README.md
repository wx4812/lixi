# Week 12：手机摄像头、ArUco识别与距离测量

## 一、实验目的
本次实验基于WSL Ubuntu 22.04与ROS2开发环境，利用手机摄像头作为视觉输入，借助Tailscale搭建跨设备虚拟网络通道，打通手机与WSL之间的低延迟视频流传输。
通过OpenCV和ArUco标记库完成视觉标志物的实时检测、相机畸变标定，最终实现目标标记与机器人之间距离、方位的精确解算。
通过本次实验，掌握跨设备远程图像通信、ArUco机器视觉定位、三维测距的完整流程，理解机器人如何通过视觉感知周边目标位置，为后续机器人自主导航、目标追踪等高级功能打下感知层基础。

## 二、实验环境
1. 开发平台：WSL2 + Ubuntu 22.04 + ROS2 Humble
2. 组网工具：Tailscale（手机端 + PC端，同一账号组网互通）
3. 软件依赖：Python3、Flask、Flask-SocketIO、OpenCV、ArUco视觉工具包
4. 硬件设备：智能手机（支持浏览器摄像头权限）、标准ArUco打印标定板

## 三、实验任务
1. 拉取本次week12课程初始实验代码，完成Python运行依赖的全部安装
2. 运行相机桥接服务程序，建立手机浏览器到WSL的双向视频传输链路
3. 手机端访问Tailscale虚拟IP地址，授权摄像头，完成画面实时推流
4. 接收并预览手机传回的实时画面，完成原始图像本地保存
5. 调用OpenCV ArUco模块，实现标记图案识别、角点精准定位
6. 完成相机内参标定，修正镜头畸变误差
7. 通过位姿解算，计算ArUco标记相对摄像头的物理直线距离与水平角度
8. 完成「手机拍摄→网络传输→图像识别→测距输出」的完整闭环实验
